# 🚌 Пассажирам.РФ

**Веб-платформа для обучения водителей общественного транспорта**

Учебный проект, разработанный в рамках подготовки к демонстрационному экзамену по веб-разработке.

---

## 📋 Описание проекта

Платформа позволяет пользователям подавать заявки на обучение вождению автобусов, электробусов и трамваев, отслеживать статус заявок и оставлять отзывы после завершения обучения. Администраторы могут управлять заявками и менять их статусы.

---

## ️ Технологии

### Backend
- **Python 3.8+**
- **Flask 2.3+** — веб-фреймворк
- **Flask-SQLAlchemy** — ORM для работы с базой данных
- **Flask-Login** — управление сессиями пользователей
- **Werkzeug** — хеширование паролей
- **SQLite** — база данных

### Frontend
- **HTML5 / Jinja2** — шаблонизатор
- **CSS3 / Bootstrap 5.3** — стилизация
- **Bootstrap Icons** — иконки
- **JavaScript** — интерактивность (модальные окна)

## ⚙️ Установка и запуск

### 1. Клонируйте репозиторий
```bash
git clone https://github.com/ваш_логин/passangire_rf.git
cd passangire_rf
```

### 2. Создайте виртуальное окружение
==Windows:==
```powershell
python -m venv venv
venv\Scripts\activate
```

==Linux/macOS:==
```bash
python3 -m venv venv
source venv/bin/activate
```

### 3. Установите зависимости
```bash
pip install -r requirements.txt
```

### 4. Запустите приложение
```bash
python app.py
```
### 5. Откройте браузер и перейдите по адресу: http://127.0.0.1:5000

## 🗄️ База данных

Проект использует **SQLite** — легковесную файловую базу данных. Файл `app.db` создаётся автоматически при первом запуске.

### Таблицы:

**`users`** — пользователи системы

- `id` — уникальный идентификатор
- `login` — логин (уникальный)
- `password_hash` — хешированный пароль
- `fio` — ФИО
- `birth_date` — дата рождения
- `phone` — телефон
- `email` — email
- `role` — роль (user/admin)

**`applications`** — заявки на обучение

- `id` — уникальный идентификатор
- `user_id` — связь с пользователем (Foreign Key)
- `transport_type` — тип транспорта (Автобус/Электробус/Трамвай)
- `start_date` — дата начала обучения
- `payment_method` — способ оплаты
- `status` — статус заявки
- `created_at` — дата создания

**`reviews`** — отзывы пользователей

- `id` — уникальный идентификатор
- `application_id` — связь с заявкой (Foreign Key)
- `user_id` — связь с пользователем (Foreign Key)
- `rating` — оценка (1-5)
- `text` — текст отзыва

## 🔐 Безопасность

- ✅ Пароли хранятся в **хешированном** виде (Werkzeug `generate_password_hash`)
- ✅ Защита от **SQL-инъекций** через ORM SQLAlchemy
- ✅ Проверка прав доступа на уровне роутов (`@login_required`, проверка роли)
- ✅ Валидация данных на стороне клиента (HTML5) и сервера (Python)
- ✅ Защита от отправки отзывов за чужие заявки
